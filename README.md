# RTP -  Real-time Transport Protocol

Библиотека, реализующая протокол передачи трафика в реальном времени.  Не включает в себя реализацию протоколов установки сеанса.

Поддерживает нативную компиляцию ([Native AOT](https://learn.microsoft.com/ru-ru/dotnet/core/deploying/?pivots=visualstudio#native-aot-deployment)) под определенную платформу.

В дальнейшем планируется создание [FFI](https://en.wikipedia.org/wiki/Foreign_function_interface)
